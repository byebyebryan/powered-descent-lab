# Saved study presentation

These adapters create new editions from retained timing-reference and
coast/ignite captures. They call the maintained rich renderer and optional
neutral `pd-report` study components. They execute no policy, controller,
simulation, replay or training. Source captures, manifests and prior report
editions are immutable.

The [plan](../../docs/report_study_qol_plan.md) and
[execution record](../../docs/report_study_qol_execution.md) own scope and receipts.
`render_studies.py ROOT timing|rl NEW_OUTPUT [--pilot]` requires a compiled
`pd_coast_native` library on `PYTHONPATH`. It writes create-only specifications
under an existing allocated ROOT and a new absolute report edition. The pilot
uses labelled retained software subsets. Run each allocation once; a reserved
or failed output is preserved and a subsequent correction needs a new edition.

Study data is presentation, not a qualification authority. Frozen claims and
source intervals remain fixed while filters show descriptive selected subsets.
Fuel differences require both verified landings. Missing metrics, unsupported
inputs and unscheduled variants cannot become zero-valued successful pairs.
Costs retain their separately declared original/repetition denominator.

The common tree, focused previews, rich tools, static Plotly fallback and raw
evidence links remain intact. Study source bindings record original evaluations
and decisions, renderer/library/spec hashes and zero native transitions.
Report publication and server lifecycle are separate actions; this adapter
neither publishes nor starts/stops a server.
