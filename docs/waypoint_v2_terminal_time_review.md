# Waypoint V2 terminal time primary review

## Decision

Accept the bounded constructor research checkpoint. The
[results](waypoint_v2_terminal_time_results.md) meet its 8/8 clear landing,
39/39 airborne witness and four former NoNominal terrain/replay/reserve targets
without changing acquisition or margins. The preceding ground-constructor
integration blocker is resolved on the studied inputs. Recommend a separately
planned opt-in runtime integration and unchanged full mission gate; do not
claim usable-planner acceptance or promote a default here.

This is a separate primary contract review after implementation and final
evidence, not an independent-agent review. Luna supplied the bounded pure helper;
the primary retained coupled decisions, adapter integration and acceptance.

## Construction and execution findings

The approved baseline-first rule is implemented without neighboring-tick
retries, fitted case durations or terrain-sensitive ranking. Exact discrete
anchors are upward-even-rounded, clipped against no-reversal/deadline limits,
deduplicated and checked by the existing forward validator. Signed, near-zero,
small-interval and nonfinite cases have focused tests. Geometry that duration
cannot repair remains a finite rejection, not another seed family.

The original acquisition evaluator runs once per seed. Cached plans match the
original solver in integration tests; all 664 actual seed records preserve
acquisition fields against the sealed old study. All 1640 coast identities and
319 valid baseline screens remain identical. The old 51 characterization and
25 terminal helper bodies remain unchanged. The row adapter preserves ordinary
prefix reconstruction, materializer, executable shortlist ordering and replay;
only timed seed selection, traces and demand reporting differ.

The matched-entry gate reproduces old actual S/T and safe contacts before the
broad run. Its passing alternative references remain explicitly analytical;
they are not flights from an instantly rotated old entry. The subsequent ground
trials independently establish actual preparation/acquisition/coast/terminal
execution. All eight first valid proposals land within the original clock and
fuel history, with raw safe contact, reserve and thrust fractions below 0.925.
The source full-thrust support phase is correctly separated from acquisition
and terminal margin reporting.

Airborne inputs use complete ordinary prefix replay and exact full-state
agreement, not snapshot initialization. All 39 retain landing witnesses; all
four designated recoveries keep actual-terrain success. New global admissions
can change ranking, so preservation is measured rather than inferred from
retaining baseline times. Eight changed airborne first proposals remain safe;
every row retains its old first-valid terrain/reserve classification.

Nominal success and terrain acceptance remain distinct. Seven local first
proposals remain terrain blocked and two more fail reserve despite landing.
The evaluator does not select a lower-ranked proposal because it clears terrain.
The synthetic low-fuel miss and uphill terrain block remain visible.

Two analytical admissions fail the unchanged backend shape check before a
landing witness exists. Both obtain a valid proposal within the three-attempt
cap. These rejected trials are retained; null body/thrust metrics prevent an
empty phase list from becoming a false acceptance. First valid proposal means
executable target-plane contact plus endpoint and independent replay agreement,
not merely the first analytical trial or a terrain-successful later witness.
The shape restriction is a remaining coverage limitation, not a reason to
expand this pass or assert impossibility.

## Evidence and integration review

Pinned corpus, diagnostic and prior-study hashes protect the intended input
population. Source/input bindings are sorted, checked before/after and independently
verified; output remains create-only. Missing inputs, nonfinite construction,
command/replay disagreement and source tampering are integrity failures.
Ordinary finite misses remain research results. The CLI exposes the new opt-in
identity without touching the old characterization or runtime identities.

The two complete final-source summaries/bindings match byte for byte across
47 retained and eight synthetic rows, with 252 verified bindings and no integrity
errors. Nondeterministic timings are deliberately separate. Research row wall
time includes simulation/audit and is not a runtime performance certificate.
The additional analytical work remains within the frozen finite budget; it is
not automatically cheaper than the previous constructor.

Workspace tests pass 904 with three ignored, all fifteen focused timing/CLI
tests pass, and the two explicitly requested diagnostic archive tests pass.
Corpus/tamper, fake-suite, structural/input, formatting, preservation and
whitespace checks pass. Strict Clippy's sole unchanged baseline lint remains
disclosed; the narrow allowance passes with other warnings denied. Accept that
exception without making an unqualified strict-clean claim.

The implementation preserves old identities by copying the small row-orchestration
path and using existing helpers. That is acceptable research isolation, not a
reason to copy it into the runtime planner. A later production adapter should
share the tested construction logic and preserve the same finite failure types.

## Next-pass boundary

The next question is integration coverage, not another timing/acquisition search.
Plan the smallest opt-in adapter connecting this current-state constructor to
the existing direct-first, terrain-audit, local-clear and actual-handoff loop.
Validate ground launch once, then airborne starts using their actual state,
remaining fuel and absolute deadline. Never prepare an airborne state as if it
were grounded. Keep interior terrain outside nominal choice and retain old
runtime paths for comparison and rollback.

Only executable nominal proposals proceed to terrain audit. A finite constructor
miss must remain distinguishable from a terrain obstruction; it cannot justify
a waypoint solely to hide lack of construction coverage. A terrain rejection
still asks for one bounded local clearing piece, not proof of end-to-end landing
after that waypoint.

Require the unchanged repeated-handoff 32-case matrix: 8/8 clear, at least 13/16
ordinary, at least 2/4 per family and the existing reference, replay, integrity
and failure-semantics gates. The retained runtime policy 2 result remains 12/16
ordinary; 39 witness rows do not replace that denominator. Newly generated
handoffs can differ from this corpus. Freeze integration/ranking/fallback rules
and a limited revision/stop budget before those runs, then review the measured
complete loop. No implementation of that later phase is authorized here.

No runtime policy/default/local acceptance/physics change, commit, push or
deployment occurs in this checkpoint.
