# Ballistic phase transition and recovery consistency pass

[Documentation home](README.md) · [Finite correction reference](ballistic_finite_correction_results.md)

This authorized opt-in pass checks the finite motion between powered correction,
coast and terminal control. The frozen reference lands 786 of the original 1000
worlds. Six early regression cutoff states fail a mathematical actual-rotation
screen, while none of the 201 landed early destination commits do. Native checks
must establish that mechanism before changing admission. A separate recovery
diagnostic compares the existing command family over a common response horizon.

## Fixed behavior boundaries

Preserve initial terrain-blind construction, 32 profiles, waypoint placement and
ranking, four local proposals, physical reserves/contact guards, source replay,
command order, absolute clocks, fuel, correction cap and original deadline.
No forced burn completion, blanket tilt exclusion, extra recovery commands,
waypoint-energy objective, general optimizer or default promotion. Policy 3,
accepted reports, root navigation and report-server state remain unchanged.
Commits and pushes are outside this pass.

## Separate mechanisms

1. A behavior-identical probe records native coast settling, terminal takeover
   and common-horizon recovery queries, plus existing terminal frame metrics.
2. An actual-rotation coast ablation checks the engine-off motion through its
   finite turn to upright and ordinary short guard. The geometric remaining
   coast must not borrow an instantaneous attitude change.
3. A terminal-takeover ablation propagates two seconds of the exact configured
   controller feedback and ordinary guards, without demanding a complete landing
   suffix. A declined takeover is not a terrain obstacle or immediate mission
   failure. Preserve a valid active correction or checked coast and recheck on
   the existing planning cadence.
4. A pad-clearance ablation uses the existing body-containment/reserve convention
   to protect descent while recentering outside the landing corridor. It cannot
   relax a reserve or contact rule. Only implement a bounded correction supported
   by native queries; preserve ordinary controller defaults and the standalone
   coast-to-terminal preview/execution path. The adapter wraps only the normal
   configured terminal entry.
5. Recovery remains diagnostic: record the same four choices at earlier actual
   planning states with a common existing response horizon. Distinguish useful
   response room from a short-safe support command and from queued turn/burn
   transitions. A passing short query is not a landing certificate.

Retain the rich common reports and expose controller metrics already produced
by terminal guidance. Do not replace or simplify those reports.
